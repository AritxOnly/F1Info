# F1Info 0.5.7

本次更新完善阔折叠和平板布局，并同步 Deadliner 的柔光玻璃与导航体验。

- 新增阔折叠外屏、展开屏和平板的自适应布局；主页、赛程、积分榜和 Live 支持宽屏双栏。
- 顶栏与两栏内容共享连续的浮光背景，内容滚动至顶栏下方时驱动柔光玻璃变化；切换 Live 时保持顶栏高度一致。
- 侧栏展开时推开内容，内容区可直接交互；侧栏收起后顶部导航居中。
- 保留主页车手、车队海报与横滑分页，针对阔折叠外屏调整布局，并修复小屏赛道图异常缩小。
- 宽屏设置及子页改用 Sheet，关闭后保留当前页面和选中项。
- 宽屏赛程、积分榜选中条目后直接更新详情栏，不再显示多余返回按钮。
- 同步玻璃采样、亮边、阴影与导航按压反馈。

Android 13 及以上；版本码 16。APK 沿用现有发布证书签名，可覆盖安装旧版本。
