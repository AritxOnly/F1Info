# F1Info Android MVP

## 背景
空 Android 工程，构建 com.aritxonly.f1info；BoxBox 附件作为版式参考，MIUIX 为唯一颜色和控件体系，迁移 Deadliner 柔光玻璃。

## 目标
交付可安装 APK：三底部 Tab（首页、赛程、积分榜），首页两个关注车手和一个车队积分轮播、下一场完整周末安排；全赛季赛程、赛道地点与详情；车手/车队积分榜、冠军 TopDownloads 图标。关注可配置并持久化。真实数据来自 Jolpica，支持缓存、刷新、错误重试、空榜状态。

增加 2×2 Glance 小组件：仿 Deadliner 紧凑卡片，12dp 内容边距与三行关注积分，下一场/时间/缓存标识；随应用数据、关注、主题改变更新，点击打开应用，首次无缓存引导加载。

UI 补充验收：使用 MIUIX Scaffold/TopAppBar，语义 surface/surfaceContainer 角色；顶栏迁移 Deadliner 自适应 TopBarIconButton 与显现曲线；分类使用 ImmersiveTextTabRow，底部浮动导航使用图标在上文字在下的 Stacked 布局，仅三 Tab。关注可从积分榜详情直接标记并选择替换车手。普通与强调内容卡片统一 SettingsSection 24dp（用户要求覆盖原强调 48dp），Dialog 40dp、Sheet 36dp 保持 Deadliner 源参数。

## 非目标
直播、付费、账户、推送、iOS/HarmonyOS 客户端。不展示伪造实时积分或随机赛道轮廓。

## 用户场景
首次启动加载当前赛季；选两名车手与一支车队；切换三个 Tab；查看任意比赛的练习/排位/冲刺/正赛时间及赛道信息；离线读取上次成功数据；失败重试。

## 验收标准
- Gradle assembleDebug、单元测试、lint 通过，产出 APK。
- 三 Tab 可切换，榜单两种分类，比赛与车手/车队详情可打开、关闭。
- 关注人数约束 2+1；保存后跨重启保持；数据源未返回的关注项解释缺失。
- 时间按设备时区转换，缺失时间标注待公布，赛季结束显示已完赛。
- 网络失败时展示缓存状态或可重试错误，不把样例当真实数据。
- 无 Material UI/颜色引用；迁移源版本、修改及 API 证据有记录。
- 最大核心代码文件不超过 1000 有效行。

## 风险与约束
Jolpica 无肖像或赛道长度/圈数，赛道地理信息与官方百科链接来自 API，轮廓另用开源 f1-circuits GeoJSON 并注明来源；缺失项不编造。依赖 MIUIX 0.9.4-rc01，Android 33+。无原工程与 breaking change；完成主要代码批次后统一编译。设备验证取决于可用模拟器。

## 沉浸改版
首页迁移 HyperModifier/Deadliner 关于页三层动画浮光，使用车队品牌装饰色，MIUIX 仍控制基础语义色与控件；轮播切换同步浮光颜色。比赛/车手车队/关注/设置使用有返回按钮的二级页面，隐藏底部导航，保留上级滚动位置。顶部分段 Tab 移除固定 materialProgress，自动采纳顶栏滚动进度；页面未滚动时为普通容器，滚动后渐进玻璃。内容卡片统一 24dp。

## 小组件扩展验收
浮光下方渐变到 MIUIX surface。新增四类组件：赛程 2×2/4×2/4×4（赛道图、下一场时间、全周末、近几站），关注车手肖像积分 2×2（可选两个关注槽位），车手榜/车队榜 4×2/4×4（领先者图像或车队标识、前三或更长列表）。布局随桌面尺寸响应，未知赛道不编造；缓存/主题/关注更新仍同步，轻触打开对应页面。发布 APK 延续当前 F1Info 独立签名。

二级页面返回图标统一 MiuixIcons.ChevronBackward，保留自适应 TopBarIconButton。

## 导航与背景修正 0.3.1
使用当前 MIUIX miuix-nav NavDisplay + MiuixDefault 进入/退出二级页面并支持返回手势；按页面分别持有 backdrop，避免转场交叠导致录制循环。导航保存路由种类与实体 ID，详情按数据恢复。整页背景延伸至状态栏，TopAppBar 自带 systemBars 顶部安全区且不重复加 padding；移除榜首局部矩形 HeroWash，整页色彩由当前榜首车队驱动。页面卡片左右外边距各 16dp（内部内容边距保留）。使用原证书签名交付。

车队展示配合官方品牌 Logo 与 2026 赛季发布图片；公开图源有严格俯视与高角度摄影之分，来源角度逐项记录，不把旧赛季或示意车型当成当前赛车。首页、车队榜首、详情复用同一组件。
小组件新增全局背景不透明度 0%–100% 设置，MIUIX Slider，持久化并更新全部已添加组件；仅背景受影响，文字及图像保持原不透明度，预览使用真实 RemoteViews。

赛车从原发布摄影提取透明主体，去除摄影底色和地面投影，不再用渐隐遮罩掩盖矩形图片；保留原摄影视角，未收录正俯视的车队明确采用其他角度。

## 0.3.2 高清与沉浸修正
- 车手使用 Formula 1 官方无 transform 原图；在线加载具备内存、磁盘缓存和离线资源回退。赛车直接使用官方 3392px 原生透明背景渲染图，不再手工抠图；当前官方素材为侧视角。
- 普通列表点击反馈覆盖屏幕宽度，内容仍保持 16dp 外边距；卡片反馈覆盖卡片边界。
- 二级页滚动容器全屏，顶部和底部安全区是内容 padding，不能裁剪滚动视口；系统导航栏透明且不强制对比遮罩。
- 首页使用 MIUIX SmallTopAppBar，仅保留操作按钮，不再展示应用名称和空白大标题区。
- 追加：车手照片改用当前赛季官方个人页 1600px 上半身原图；Logo 必须从官方页面解析真实素材地址并核验尺寸；获取官方车号图形，在车手积分行中展示车号标识，车队积分行展示 Logo。二级车手资料展示车号图形。
